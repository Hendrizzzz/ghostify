# Support

Thanks for using Ghostify. Here's how to get help:

## Something broke on Instagram / Messenger / Facebook?

1. Reload your open instagram.com, messenger.com, and facebook.com tabs after
   installing or updating — the extension starts before page load.
2. Check the public status page with dated verification per platform and signal:
   <https://ghostify-extension.vercel.app/status>
3. If a control stopped working after a Meta update, please tell us via the
   guided **Help & feedback** form — dated reports drive the verification feed:
   <https://github.com/Hendrizzzz/Ghostify/issues/new?template=help_feedback.yml>

## Questions about behavior or privacy

- Read [PRIVACY.md](PRIVACY.md) for what the extension does and does not touch,
  and [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) for boundaries.
- Ask via the question form:
  <https://github.com/Hendrizzzz/Ghostify/issues/new?template=question.yml>

## Bugs and feature ideas

- Bug report form:
  <https://github.com/Hendrizzzz/Ghostify/issues/new?template=bug_report.yml>
- Idea form:
  <https://github.com/Hendrizzzz/Ghostify/issues/new?template=feature_request.yml>

Please do not include private messages, credentials, or account-sensitive
details in any report.

## Security issues

Do **not** open a public issue. Follow [SECURITY.md](SECURITY.md) and report via
private GitHub security advisories.
